# 📰 নিউজ পোর্টাল ওয়েবসাইট

একটি সম্পূর্ণ পেশাদার নিউজ পোর্টাল ওয়েবসাইট যেখানে ব্যবহারকারীরা নিউজ ব্রাউজ করতে, সার্চ করতে এবং অ্যাডমিন হিসেবে নিজেদের নিউজ পোস্ট করতে পারে।

## 🎯 ফিচার

### 1. 🏠 হোমপেজ (index.html)
- **ফিচার্ড নিউজ** - বড় ছবি সহ টপ নিউজ
- **সর্বশেষ খবর** - নতুন নিউজ গ্রিড
- **সাইডবার** - এই সপ্তাহের পাঠকপ্রিয় নিউজ
- **সোশ্যাল মিডিয়া লিংক** - Facebook, YouTube, Twitter, Instagram
- **বর্তমান তারিখ** - বাংলা ফরম্যাটে প্রদর্শিত

### 2. 📰 সব খবর (news.html)
- সমস্ত নিউজ একসাথে দেখা যায়
- ক্যাটাগরি অনুযায়ী ফিল্টার করা যায়
- সার্চ ফাংশনালিটি সহ

### 3. 🔐 অ্যাডমিন প্যানেল (admin.html)
- সহজ লগইন সিস্টেম
- নিউজ পোস্ট করার ফর্ম
- ছবি আপলোড অপশন
- সম্প্রতি পোস্ট করা খবর দেখা যায়
- নিউজ ডিলিট করার অপশন

### 4. 🎨 ডিজাইন ফিচার
- সম্পূর্ণ রেসপন্সিভ (মোবাইল, ট্যাবলেট, ডেস্কটপ)
- সুন্দর কালার স্কিম
- স্মুথ এনিমেশন এবং হোভার এফেক্ট
- দ্রুত লোডিং

## 📂 ফাইল স্ট্রাকচার

```
নিউজ পোর্টাল/
├── index.html          (হোমপেজ)
├── news.html           (সব খবর পেজ)
├── admin.html          (অ্যাডমিন প্যানেল)
├── style.css           (স্টাইলশীট)
├── script.js           (মেইন জাভাস্ক্রিপ্ট)
├── admin.js            (অ্যাডমিন জাভাস্ক্রিপ্ট)
├── news.json           (নিউজ ডাটা)
├── logo.svg            (লোগো ছবি)
├── README.md           (এই ফাইল)
└── images/             (ছবির ফোল্ডার)
```

## 📝 নিউজ পোস্ট করার পদ্ধতি

1. `admin.html` এ যান
2. ইউজারনেম এবং পাসওয়ার্ড দিয়ে লগইন করুন
3. নিম্নলিখিত তথ্য পূরণ করুন:
   - খবরের শিরোনাম
   - বিবরণ
   - ক্যাটাগরি নির্বাচন
   - ছবি (URL বা আপলোড)
   - লেখকের নাম
4. "নিউজ পোস্ট করুন" বাটনে ক্লিক করুন

পোস্ট করা নিউজ সাথে সাথে হোমপেজে দেখা যাবে!
